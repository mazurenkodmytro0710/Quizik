## 18. Správne priraďte význam jednotlivým parametrom stratégií riadenia zásob (P1, P2):

- parameter **s** → zásoby sa dopĺňajú v okamihu, keď ich stav klesne pod hranicu s *(bod objednania)*
- parameter **t** → zásoby sa dopĺňajú v pravidelných časových intervaloch dĺžky t *(periodické dopĺňanie)*
- parameter **S** → zásoby sa dopĺňajú na úroveň S *(maximálna úroveň zásob)*
- parameter **x** → zásoby sa dopĺňajú o množstvo x *(pevné objednávacie množstvo)*

✅ Správne priradenie:
- s → P1 (bod objednania)
- t → P2 (perióda)
- S → P1 alebo P2 (cieľová úroveň)
- x → P1 (pevné množstvo)
